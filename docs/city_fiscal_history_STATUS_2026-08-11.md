# 城市政府性基金与卖地收入历史补录状态（2026-08-11）

## 本轮目标

- 对城市经济模块的 15 个目标城市补录全市口径的年度政府性基金预算收入、支出和国有土地使用权出让收入。
- 只接收可打开、可定位到表名或正文主语、可确认单位的政府/人大官方原文。
- 页面新增独立的“城市 + 财政指标 + 开始年份 + 结束年份”动态表，折线图、逐年明细和 CSV 同步筛选。

## 口径纪律

1. 全市口径优先；市本级数据不得冒充全市，直辖市的省级行政区等同全市。
2. 决算数标 `official`；年初预算执行报告或预计执行数标 `official_preliminary`。
3. “国有土地出让相关/有关收入”不自动映射为严格的“国有土地使用权出让收入”。因此常州 2020、2021 只录政府性基金总额，没有把相关收入录成卖地收入。
4. 搜索摘要、媒体、评级报告只作发现线索；未打开官方原文前不入库。
5. 缺年不补零、不插值、不按省级数据或基金收入比例估算。

北京 2024 最终决算附表值为：政府性基金收入 2094.8526 亿元、国有土地使用权出让收入 1920.5376 亿元。此前 2094.9 亿元的预算执行数由最终决算精确值替换。

## 本轮入库后覆盖

- 政府性基金收入：30 个城市-年记录，覆盖 13/15 城，期间 2020—2025。
- 国有土地使用权出让收入：14 个城市-年记录，覆盖 9/15 城，期间 2020—2024。
- 政府性基金支出：23 个城市-年记录，覆盖 12/15 城，期间 2020—2025。
- 上述是当前 API 中可直接筛选的年度记录数，不代表 15 城每年都已齐全；动态表会显式标记缺年。

## 当前仍缺的直接官方序列

- 合肥：合肥市财政局和安徽省财政厅在当前网络返回 JS 验证页或 GeoBL 403。没有绕过验证，也没有采用评级报告数字。
- 长沙：湖南省财政厅决算 PDF 可直接核验全省基金收入和长沙债务行，但没有“长沙市政府性基金收入”分地区表；长沙市财政原文当前未能稳定访问，所以保持缺失。
- 多数城市的历史卖地分项仍少于基金总额：只有表内明确写“国有土地使用权出让收入”且能确认全市列时才录入。

## 页面交互

- 路径：`/city-economy` → “单城详情” → “城市财政动态表”。
- 控件：城市、财政指标、开始年份、结束年份。
- 图：选中期间形成完整年度轴；缺失值为 `null`，折线断开。
- 表：逐年列出实际值或 `missing`，同时显示地区口径、状态、官方来源和解析说明。
- CSV：导出当前筛选范围，缺失年份也保留，便于后续审计和补录。
