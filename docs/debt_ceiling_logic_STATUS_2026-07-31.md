# 债务限额推演逻辑优化状态（2026-07-31）

## 本次变更

- 更新管线改为逐条幂等 upsert；网络或解析失败时保留旧的已核验记录，不再先删全表。
- 2026 年官方限额独立作为限额路径锚点；余额路径仍锚定最新实际年末值。两边样本期、点数和数据状态分别披露。
- 新增“当前年度地方限额使用进度”：同年批准限额对照财政部月度地方债余额，缺月不插值、不连线。
- 新增一致性压力测试：国债余额、地方债余额和付息增速同时作 -2/0/+2 个百分点调整；限额与收入增速保持不变。该表无概率含义。
- 页面明确区分 official（原始限额/余额）、derived（剩余空间/使用率）与 scenario（未来路径/触线年份）。

## 边界

- 限额是政策变量，“触线”只表示在给定增速下需要再次提高限额，不是违约、偿付失败或所谓“死亡上限”。
- 月度进度只做同年限额对照；不按上半年速度外推年末，也不填补 2026-03 缺口。
- 城投债没有官方统一认定口径，本页不提供任何城投债数字。
