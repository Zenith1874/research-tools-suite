## 计算规则

存续发行额上限只累计“截至快照日已发行、尚未到期、实际发行额大于零”的已回填条款。
已知发行日在快照日之后的债券剔除；发行日缺失的债券保留并单独计数。因缺少完整的回售、
提前兑付和分期还本快照，该数是上限估计，不命名为当前余额。

```text
期末余额 = 期初余额 - 到期 + 再融资发行 + 新增融资
现金偿还本金 = 到期 × (1 - 再融资率)
估算利息 = (期初余额 + 期末余额) / 2 × 融资利率
现金偿付合计 = 现金偿还本金 + 估算利息
```

基准默认再融资率 90%、新增融资为期初余额 3%、融资利率使用存续样本发行额加权票息、
假设期限 3 年。融资宽松在基准上使用再融资率 +10pp、新增融资 +2pp、利率 -0.5pp；
融资压力使用再融资率 -20pp、新增融资 -3pp、利率 +1pp。三种路径没有概率含义，不称为
最好、最可能或最坏预测。首年只覆盖快照日后剩余年度，新增融资与估算利息按剩余天数折算。
