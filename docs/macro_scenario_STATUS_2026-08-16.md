# 宏观趋势与情景推演状态（2026-08-16）

## 本轮目的

把已有中国宏观、央行、利率、房地产 observation 转成可验证的条件情景，响应老蛮频道转录中反复出现的“趋势延续、政策冲击、信用收缩、房价路径和未来情形”问题。

本轮新增独立页面 `/macro-scenario` 和只读接口 `/api/macro-scenario`。它不修改原始观测表，也不把情景结果写回 SQLite。

## 当前功能

- 17 个指标入口，覆盖 GDP、工业、消费、投资、价格、就业、外贸、M1/M2、贷款、社融、LPR、商品房销售面积和 BIS 实际房价。
- 每个可用指标生成上行/基准/下行三条未来路径。
- 变化率指标使用百分点变化分布；指数/水平指标使用对数变化。
- 变化分布使用连续历史尾段的 75/50/25 分位，并按 `0.96` 逐期衰减，避免把短期冲击直线外推多年。
- 固定种子移动块重抽样，输出 P10/P50/P90 敏感性区间。区间不是概率，也不是统计置信区间。
- 滚动起点回测，输出 MAE、RMSE、方向命中率和上/下行包络覆盖率。
- 明确处理统计发布的年初合并月份：工业、固定资产投资和商品房销售面积的 1—2 月记为 2 月；当前零售来源的年初合并值记为 3 月。
- 指标目录标记 `missing`、`insufficient_sample`，不以零值或相近指标代填。
- 页面同时列出工业利润、产能利用率、农民工、青年就业、银行净息差/不良率、国别产品贸易、政策事件和年龄别死亡等当前缺口。

## 模型边界

```text
未来路径 = 最新观测 + 历史变化分位 × 逐期衰减
```

历史回测在每一个起点重新估计变化分布，只读取该起点之前的连续历史。上行/下行只表示指标值较高/较低，不自动表示整体经济好/坏；CPI、PPI、失业率和 LPR 必须与其他指标联读。
