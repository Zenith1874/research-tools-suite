# 中美 GDP 模块状态（2026-07-22）

## 本次新增

- `/gdp`：中美全国、 中国省级、美国州级三个交互页签。
- 全国现价美元 GDP：World Bank 经 FRED 官方镜像，1960 年起；页面明确说明其增长同时受本币名义增长和汇率影响。
- 美国州级 GDP：BEA `SAGDP` 官方年度文件，50 州及华盛顿特区，1997 年起；保留名义 GDP、实际 GDP并透明推导实际增速。
- 地区页的历史图与排行各自占满整行，不再左右二分；支持排行年份、历史起止期间、指标、搜索和多选地区联动；全国图支持线性/对数纵轴。
- 新增“地方财政”页签：Census ASFIN 免 key 官方打包文件提供美国州政府本级收入、支出、税收、利息与债务；图表、排行和期间筛选均整行展示。
- 中国31省 GDP：国家统计局年鉴官方 XLS/JPG，2010–2024 连续15年，共465条；缺值不插值。
- 中国31省一般公共预算收入、税收收入、一般公共预算支出：统计局年鉴官方 XLS/JPG，均为2010–2024连续15年，每项465条、合计1395条。
- 中国31省一般债与专项债：财政部全国财政决算分地区表，2018–2024。14张年度表中12张已成功入库372条；财政部当前持续502的2019、2022一般债页面保留缺口。
- 省级财政决算 PDF 继续补统一表没有的卖地、基金收支、还本付息字段：首批北京 2022、上海 2023、广东 2023共抽取18个值；与统计局/财政部统一表重叠的7条以统一表作为规范来源，最终保留11条独有细项；同时保留严格 CSV 导入契约。

## 中国省级边界

国家统计局 `data.stats.gov.cn` 在当前海外网络和真实浏览器中均返回403，不能把搜索摘要当数据。中国统计年鉴2010–2013优先读取官方 XLS；2014–2019、2021–2024只有高清 JPG 时使用本地 RapidOCR。OCR 固定31省顺序，要求整表恰好31省（允许一个置顶合计行）、目标列最低置信度0.90，并校验收入不低于税收；任一条件失败则整张表不入库。2020年同时存在 XLS/JPG，逐省质检结果：GDP 31/31完全一致；财政93个值均在图片两位小数舍入误差0.005亿元内。财政部地区债务页逐页独立更新，单页502不影响其他年份。省级财政厅 PDF 必须带 `%PDF` 文件头，解析锁定决算数及全省/全市、省级/市级范围；缺字段不补、错误页不入库且不清旧值。

## 复现

```bash
python.exe -m unittest tests.test_gdp_service tests.test_regional_fiscal_service -v
curl -X POST http://127.0.0.1:5001/api/gdp/update
curl http://127.0.0.1:5001/api/gdp/data
```

中国省级官方文件导入：

```powershell
$env:CHINA_REGIONAL_OFFICIAL_CSV='D:\path\reviewed_china_regional_official.csv'
Invoke-WebRequest -Method Post http://127.0.0.1:5001/api/gdp/update
```

CSV 每行必须包含 `region_code,region_name,period,indicator_code,value,unit,source_url`，
其中 `source_url` 必须是统计局或财政部门的 HTTPS 原文链接。示例模板不含真实值，不能直接导入。
