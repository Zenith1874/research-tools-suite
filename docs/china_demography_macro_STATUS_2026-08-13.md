# 中国人口与婚姻家庭宏观序列状态（2026-08-13）

## 2026-08-17 出生人口历史链路增补

本次确认“出生人口”图从 2002 年开始不是前端截断：仓库内 `CN_BIRTHS` 官方绝对数快照本来就是
2002—2025，共 24 期。为满足历史趋势和情景推演需要，又接入了国家统计局《中国统计年鉴 2025》
“2-1 人口数及构成”中的 1977—2009 年末人口，并与现有 2010—2025 年人口快照接成 1977—2025
无缺年人口基数。

在此基础上，dashboard/API 新增 `CN_BIRTHS_ESTIMATED`：

`出生人口估算 = 出生率（‰） ×（上年末人口 + 本年末人口）÷ 2 ÷ 1000`

该派生序列覆盖 1978—2025，共 48 期，状态固定为 `derived`；它用于历史趋势、模型输入和情景推演，
不会覆盖或冒充 `CN_BIRTHS` 官方绝对数。页面新增“出生人口：官方绝对数与历史估算”分线图，覆盖表和
API 也保留派生状态、公式和“没有单一来源发布日期”的提示。

当前边界仍明确保留：

- 官方绝对出生人口在本系统中仍为 2002—2025；2025 年为 792 万人。
- 历史估算从 1978 年开始，不把出生率反推结果当成官方绝对数。
- 国家统计局公开答复指出，1949—1981 年逐年出生人口绝对数不能从其公开年度资料中直接查得；因此本次没有伪造
  1949—1977 年绝对数，也没有把出生率序列改名为出生人口。
- 估算线与官方线可能因年鉴修订、年中人口近似和不同发布口径产生小差异；差异本身应保留给模型审计。

本次验证：`CN_POPULATION` 1977—2025 为 49 期、`CN_BIRTH_RATE` 1978—2025 为 48 期、
`CN_BIRTHS_ESTIMATED` 1978—2025 为 48 期；1978 年估算约 1745.0 万人，2025 年估算约 791.91 万人，
2025 年官方绝对数仍为 792 万人。运行 `python.exe -X utf8 -m unittest tests.test_china_demography_service -v`
通过 8 项。

## 数据与管线

- `services/china_demography_service.py` 继续只读取仓库内已核验的
  `data/china_demography_annual_official.csv`，不在同步时猜测、插值或用出生率反推出生人数。
- 导入器现在默认拒绝结构性错误：未知指标、年份格式、非有限数值、单位不匹配、未知状态、非
  HTTP(S) 来源、缺少来源名称/标题以及重复 `(indicator_code, period)` 键都会使任务失败；
  `strict=False` 仅保留兼容性的跳过模式。
- CSV 可选 `release_date`/`source_release_date` 和 `retrieved_at`/`source_retrieved_at` 字段。
  当前快照未填这些字段，故数据库和页面保持空缺；这是真实缺失，不是发布日期为同步日期。
- 同步现在只在观测值或来源字段真实变化时更新 `updated_at`。重复同步返回扫描数、变更数和保持不变数，
  不会制造虚假的新鲜度。
