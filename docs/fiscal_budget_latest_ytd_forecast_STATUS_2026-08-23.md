## 口径和限制

1. 官方同比优先用于年内增长判断；累计值直除只作为 derived 补充。
2. 全年估计公式为：`当前同截止月 YTD / 历史同截止月 YTD/全年比例`。不把 1—7 月同比直接当作全年同比，不把缺月当作 0，也不跨缺月桥接。
3. 1—7 月对全年比例受到土地结算、财政执行节奏和制度调整影响；历史样本是参考，不代表结构稳定。
4. 服务器当前默认启动环境曾指向空的 `/tmp/research_tools_runtime_*` 数据库；主库和纯函数/API 临时端口已验证。正式页面验收前，需让 5001 进程使用 `D:\claude\pboc_data.db` 后再重启看门狗。
