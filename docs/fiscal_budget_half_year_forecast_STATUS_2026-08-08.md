# 财政收支上半年到全年推演状态（2026-08-08）

## 本次修正

- 发现旧逻辑把最新上半年同比直接当作全年同比，乘到上一年全年值上；这会忽略同一科目上半年占全年比例的季节性变化。
- 新逻辑分别匹配一般公共预算收入、一般公共预算支出、政府性基金收入、政府性基金支出的 `YYYY-06` 与 `YYYY-12` 官方累计值。
- 当前年度先固定上半年官方累计值，再用历史同科目 H1/全年比例转换全年：基准使用中位数，较好/较坏使用方向一致的第25/75百分位。
- 当前年度模拟固定 2026 年上半年值，只对历史四科目 H1/全年比例做联合 bootstrap；2027 年以后继续使用历史年度增速联合模拟。模拟输出是敏感性区间，不是概率预测或官方置信区间。
- 财政部报告中的四个总量同比字段已纳入解析：一般预算收入、一般预算支出、政府性基金收入、政府性基金支出。财政部归档偶发返回 http 链接时，发现管线统一升级到官方 https 地址。

## 口径限制

- 上半年同比不能直接等同全年同比；当前模型只把同比作为背景，全年估计由 H1/全年历史比例转换。
- 历史比例可能受财政制度、土地出让结算节奏、预算执行节奏和政策变化影响；样本数量有限，模拟次数增加不会增加信息量。
- 两本账简单相加是分析视图，不等于财政部另行公布的法定综合财力或预算赤字。
