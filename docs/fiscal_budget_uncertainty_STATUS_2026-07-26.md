# 财政账本三情景与不确定性区间状态（2026-07-26）

## 目标

优化 `/fiscal-debt` 的“查看账本”模块，使一般公共预算、政府性基金和两本账简单相加都能同时比较最可能、较好、较坏三种未来点估计，并补充可复现的模型不确定性区间。

## 实现

- 保留既有三年规则外推，不改变 official 历史数据：
  - 最可能（基准）：第一年优先使用最新同月 YTD 同比，之后使用最近五个年度增速中位数；
  - 较好（改善）：收入增速 +2 个百分点、支出增速 -2 个百分点；
  - 较坏（承压）：收入增速 -2 个百分点、支出增速 +2 个百分点；
  - 所有年度增速限制在 ±20%。
- 三种点估计在页面上同时显示最终年份差额卡；点击任一卡即可同步切换收入支出、差额和付息路径。
- 新增 5,000 次联合历史冲击抽样：
  - 将同一年一般预算收入、一般预算支出、基金收入、基金支出四项增速作为一个向量整体抽取；
  - 抽样冲击围绕基准增速居中，保留四项指标的同年共同波动；
  - 固定随机种子 `20260726`，每次构建结果一致；
  - 输出三个账本未来三年的 P10、P50、P90 收支差额；
  - 历史连续年度增速向量少于 5 个时拒绝生成区间。
- 模拟结果仅存在于 API payload，标记 `scenario`，不写入数据库或 official observation。
- 页面新增方法、样本数、模拟次数、警告和两张可导出 CSV 明细表。

## 解释边界

- “较好/较坏”是 ±2 个百分点的透明压力测试，不是理论上的绝对最好或最坏结果。
- P10/P50/P90 是基于历史联合波动的模型敏感性区间，不是官方预测、经验发生概率或严格统计置信区间。
- 当前样本为 2012—2025 年 13 个连续年度增速向量。增加到十万或百万次只能降低抽样噪声，不能增加历史信息，也不能消除制度、土地市场和统计口径变化。
- 收入减支出的差额不等于法定预算赤字；两本账简单相加未抵销调入调出、结转结余和跨账本转移。

## 当前实测（本地数据库，2026-07-26）

- 锚点：2025 完整年度；第一年参考 2026-06 对比 2025-06 的 YTD 增速。
- 两本账简单相加的 2028 年点估计：
  - 最可能：-132,185.4 亿元；
  - 较好：-92,018.8 亿元；
  - 较坏：-171,751.4 亿元。
- 两本账简单相加的 2028 年模拟区间：P10 -177,859.1、P50 -155,282.3、P90 -107,277.2 亿元。
- 单次 `build_fiscal_budget_payload` 含 5,000 次模拟约 0.06 秒，计算量不是瓶颈。

## 政府性基金最新口径复核

- 财政部 2026 年上半年原文与本地库一致：全国政府性基金预算收入 15,244 亿元、官方可比口径同比 -21.6%；国有土地使用权出让收入 9,778 亿元、官方同比 -31.5%。
- 新增 `gov_fund_revenue_ytd_yoy_official`，保留原文 URL、`official` 状态和 `%` 单位；总基金收入与土地出让收入不再混用。
- 情景第一年优先读取官方基金收入同比；同时披露原始 -21.6% 与模型 ±20% 边界后实际采用的 -20.0%。2026 年基金收入基准情景仍为 46,163.2 亿元；若不设边界、机械使用 -21.6%，对应为 45,239.9 亿元，两者相差 923.3 亿元。
- 页面明确区分 2025 完整年度总览与 2026-06 YTD 最新进度，并修复官方同比卡被误标为“亿元”的单位问题。
- 增量抓取写入 2026-02 至 2026-06 官方基金收入同比；一篇 2014 年旧存档本次返回 HTTP 502，旧数据未清除，且不影响最新期。
- 回归验证：财政模块 14 项、全仓 270 项测试通过；重启后 API 与真实浏览器均显示 -21.6%、单位 `%`，控制台 0 error（仅既有 Babel 开发模式 warning）。
